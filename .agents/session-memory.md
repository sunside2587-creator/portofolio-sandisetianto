# Session Memory & Workflow Rules

1. **Awal Sesi:** Sebelum menulis kode apa pun, WAJIB baca `PROGRESS.md` dan `CONTEXT.md` untuk memahami status terakhir proyek.
2. **Selama Pengerjaan:** Kerjakan satu tugas pada satu waktu sesuai daftar `[ ]` atau `[/]` di `PROGRESS.md`.
3. **Akhir Tugas / Sebelum Sesi Berakhir:** Setiap kali selesai menyelesaikan satu fitur atau perubahan besar, WAJIB perbarui `PROGRESS.md`:
   - Ubah `[ ]` menjadi `[x]` untuk tugas yang selesai.
   - Perbarui bagian **Status Terakhir** dan **Langkah berikutnya** secara spesifik (sebutkan nama file yang baru diubah).
